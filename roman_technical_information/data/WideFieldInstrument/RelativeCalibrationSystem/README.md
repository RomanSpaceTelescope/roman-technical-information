# Roman Wide Field Instrument Relative Calibration System (RCS)

## Included folders

| Filename| Description|
|---------|------------|
| WFI_RCS_LEDP_centers_FWHM.ecsv        | Roman WFI Relative Calibration System (RCS) LEDP (LED package) measured centers and full width half maxima (FWHM).              |
| WFI_RCS_LEDP_flux_ranges.ecsv         | Roman WFI RCS LEDP low/high current range flux bounds, the resulting flux gap, and dark element/LOLO uniformity. |
| WFI_RCS_LEDP_flux_to_code_coefficients.ecsv | Roman WFI RCS LEDP flux-to-command-code polynomial coefficients for the low and high current ranges. |
| WFI_RCS_LEDP_precharge.ecsv           | Roman WFI RCS LEDP recommended precharge requirements (bands 4-6 only). |
